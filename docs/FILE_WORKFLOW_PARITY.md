## 本轮实现范围

| 项目 | 本轮行为 | 边界 |
| --- | --- | --- |
| 网络永久删除确认 | 移植旧 Fork 的网络卷分类、确认前元数据准备及身份绑定删除；确认默认焦点为取消，无“不再询问”；混合选择明确网络永久删除和本地回收数量；只消耗成功删除项目的剪贴板和选择。 | 网络永久删除不可撤销；取消确认不写入共享；执行中出错可能部分删除，保留实际错误，不修改服务器权限、不备份、不强制重试。 |
| 网络权限错误 | 从旧 Fork 整理 `NativeFileFailure`，使用缓存挂载分类，保留 POSIX 错误码；服务器拒绝不引导到本机完全磁盘访问。 | macOS 授权不能解决服务器 ACL；未知位置不猜测为本地授权问题。 |
| 详细信息列 | 现有五列的显示、顺序、宽度独立保存到文件夹；名称不能隐藏；表头右键及查看菜单入口；跨窗口同步、重启恢复、全局应用和恢复默认。 | 本轮未增加媒体/文档等更多列；未定制保持现有窄窗响应式布局，已定制使用横向滚动。 |
| 重做 | 菜单、Command+Shift+Z / Control+Y；复制、新建、移动、重命名、本地回收等使用撤销实际产生的反向记录；部分失败分别保留可重试记录。 | 当前窗口会话历史，不持久化；成功新操作清空重做分支。碰撞、对象身份变化或不可访问时拒绝，不覆盖、不重新复制已变化来源；永久删除不加入历史。 |
| 属性编辑与扩展页 | 常规页单个项目的名称编辑（取消不保存、身份预检、排他重命名、撤销/重做）；增加详细信息和权限只读页；包含完整路径、扩展名、访问日期、硬链接数、链接文字目标、UID/GID 和 POSIX mode。 | 只读、隐藏仍为只读控件；UID/GID/mode 为文件系统报告值，不能当作服务器有效 ACL。多选不提供含糊的批量重命名。 |

属性页只读取符号链接本身的元数据及目标文字，不遍历目标；目录大小统计仍不跟随链接。读取失败显示错误，不启用缺少身份的名称保存。后台统计完成或切换页签不覆盖尚未保存的名称。

## 属性写入后续拆分

以下整理为待开发项，本轮不宣称已实现：

1. **隐藏与只读**：先分别定义 macOS hidden flag、点文件名称、POSIX 写位、文件锁定和 SMB DOS 属性的映射；符号链接按链接本身处理；目录默认仅自身、不递归；权限不支持时明确报告，不静默回退。需要描述符绑定、逐项读回、部分失败和可恢复历史模型。
2. **权限编辑**：用户/组身份、POSIX 与 ACL 分开显示；以服务器实际能力决定编辑入口，不能把客户端映射 mode 当作 NAS ACL；默认不提权、不递归、不移除未知 ACL。需要单独的权限变化撤销记录，不能复用仅记录路径的文件移动历史。
3. **扩展属性及文档/媒体字段编辑**：定义白名单及每种文件格式的安全写入方式；隔离 `com.apple.provenance` 等系统管理字段；拒绝修改会损坏签名或未知格式的字段。先只读展示再逐类开放。
4. **共享页/系统扩展**：macOS 没有 Windows Shell 属性扩展页等价接口；共享配置由 SMB 服务端管理。系统级设置应使用真实系统能力，不显示不能生效的 Windows 控件。

每批都需临时夹具中的符号链接、路径替换、碰撞、无权限和部分失败验证；涉及 NAS 写入需专门的白名单夹具验收。本轮未尝试更改真实用户权限，也未创建网络测试残留。
